# Glossary

## Client

The individual or organization requesting software.

---

## Deliverable

A completed piece of work provided to the client.

---

## MVP

Minimum Viable Product.

The smallest version of software that delivers value.

---

## Repository

A Git project stored in GitHub.

---

## Sprint

A short development period focused on completing specific goals.

---

## Scope

The agreed work included within a project.

---

## Refactoring

Improving code without changing functionality.

---

## Technical Debt

Future work created by taking shortcuts today.

---

## Deployment

Making software available to users.

---

## AI Workflow

The process of using AI tools to assist development while following SEPER DIGITAL standards.
