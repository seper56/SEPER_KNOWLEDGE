# GlowZone Scorecard

## Status

Completed

---

## Overview

GlowZone Scorecard is a custom web application developed for GlowZone 360 to digitally replace and improve the company's golf scorecard process.

The application was designed to be simple, mobile-friendly, and easy for staff and customers to use.

---

## Client

GlowZone 360

---

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

---

## Features

- Digital golf scorecard
- Front 9 and Back 9 scoring
- Automatic score calculations
- Mobile responsive layout
- Player name entry
- Rules page
- Share scorecard functionality
- Advertising section
- Custom branding
- Navigation between scorecard pages

---

## Challenges

During development several improvements were made:

- Fixed score calculation bugs
- Added support for double-digit scores
- Improved mobile responsiveness
- Redesigned navigation
- Improved score sharing
- Added branding throughout the application
- Optimized layout to better match the physical scorecard

---

## Lessons Learned

This project reinforced the importance of:

- Mobile-first development
- Continuous testing
- Building reusable JavaScript
- Keeping UI simple
- Iterating based on client feedback
- Managing real-world client revisions and expectations
