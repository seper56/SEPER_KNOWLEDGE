# HTML Standards

## Philosophy

HTML provides the foundation of every SEPER DIGITAL project.

It should always be semantic, accessible, and easy to understand.

---

# Semantic HTML

Always prefer semantic elements.

Examples:

- header
- nav
- main
- section
- article
- aside
- footer

Avoid unnecessary div containers.

---

# Document Structure

Every page should contain:

- Proper DOCTYPE
- lang attribute
- UTF-8 charset
- Responsive viewport meta tag
- Descriptive page title

---

# Headings

Maintain proper heading hierarchy.

One H1 per page.

Never skip heading levels.

---

# Images

Every image must include:

- descriptive alt text
- optimized file size
- appropriate format

---

# Forms

Every form must include:

- Labels
- Validation
- Helpful error messages
- Proper input types

---

# Accessibility

HTML should support:

- Keyboard navigation
- Screen readers
- Proper landmarks
- Accessible forms

---

# Organization

Keep HTML readable.

Use consistent indentation.

Group related content together.

Avoid deeply nested structures.

---

# SEPER DIGITAL Standard

HTML should describe content, not presentation.

CSS controls appearance.

JavaScript controls behavior.
