# JavaScript Standards

## Philosophy

JavaScript should be simple, modular, and maintainable.

The goal is to solve problems clearly rather than writing clever code.

---

# Variables

Use:

const

Use let only when values change.

Avoid var.

---

# Functions

Functions should:

- Do one thing.
- Be easy to read.
- Return predictable results.

Break large functions into smaller reusable functions.

---

# Naming

Use descriptive names.

Good:

calculateInvoiceTotal

loadProjects

saveSettings

Bad:

run()

temp()

doStuff()

---

# Organization

Separate:

- Business Logic
- UI
- Data
- Utilities

Avoid mixing responsibilities.

---

# Error Handling

Always validate:

- User input
- API responses
- Local Storage
- External data

Fail gracefully.

---

# Comments

Explain:

WHY

not

WHAT

Only document complex logic.

---

# Performance

Avoid:

Repeated DOM queries

Duplicate calculations

Unnecessary loops

---

# Reusability

Whenever possible:

Write reusable functions.

Avoid duplicate code.

---

# Testing

Before committing:

- No console errors
- Mobile tested
- Forms validated
- Features verified

---

# SEPER DIGITAL Standard

Simple code ages better than clever code.
