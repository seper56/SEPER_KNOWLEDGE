# CSS Standards

## Philosophy

CSS should create interfaces that are clean, responsive, and easy to maintain.

---

# Mobile First

Always design for mobile first.

Enhance layouts for larger screens.

---

# Organization

Group styles logically.

Example:

- Variables
- Base styles
- Layout
- Components
- Utilities
- Media Queries

---

# Naming

Use meaningful class names.

Examples:

product-card

hero-section

invoice-table

Avoid:

box1

redbutton

test

---

# Colors

Use consistent colors.

Prefer CSS variables.

Example:

Primary

Secondary

Background

Text

Success

Warning

Danger

---

# Typography

Maintain consistent:

- Font sizes
- Font weights
- Line heights
- Spacing

---

# Spacing

Use a consistent spacing system.

Avoid random margin and padding values.

---

# Responsive Design

Every layout should work on:

- Mobile
- Tablet
- Desktop

No horizontal scrolling.

---

# Performance

Avoid duplicate CSS.

Remove unused styles.

Keep selectors simple.

---

# SEPER DIGITAL Standard

Good CSS should be predictable, reusable, and scalable.
